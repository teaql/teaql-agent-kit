# Security Policy

## Supported Versions

Since `teaql-agent-kit` primarily contains documentation and prompts rather than executable software code, traditional vulnerability patching applies differently here. However, we ensure that our documentation and guidelines do not endorse insecure coding practices.

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security issue or find that our guidelines promote an insecure pattern, please do NOT open a public issue.
Instead, please send an e-mail to our security team via [security@teaql.dev](mailto:security@teaql.dev). We take all security concerns seriously and will update our documentation promptly.
