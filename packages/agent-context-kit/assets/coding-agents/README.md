# Coding agent icons

Copied from the companion
[TeaQL Agent Kit](https://github.com/teaql/teaql-agent-kit) so both projects use
the same coding-agent presentation.

The marks originate from
[Lobe Icons](https://github.com/lobehub/lobe-icons),
`@lobehub/icons-static-svg@1.95.1`, under the bundled MIT license. Each mark is
centered on an unchanged white rounded tile for light and dark GitHub themes.

The OpenCode, Xiaomi MiMo, and DeepSeek marks were added from
`@lobehub/icons-static-svg@1.90.0` using the same tile treatment. Hermes Agent,
Cline, Kimi, Qwen, GitHub Copilot, and Kiro come from
`@lobehub/icons-static-svg@1.95.1`. The Pi tile derives its geometry and
`#50b4e6` color from the mascot in the
[MIT-licensed Pi project](https://github.com/earendil-works/pi); see
`PI-LICENSE`. The Kilo tile uses the official yellow-on-black SVG from the
[MIT-licensed Kilo Code repository](https://github.com/Kilo-Org/kilocode).
See `KILO-LICENSE`.
Crush does not publish a vector application icon; its tile uses the project's
documented heart identity and Charple primary color as a simple original mark.

The Octop tile centers the [official Octop favicon](https://github.com/TencentCloud/Octop/blob/4811eb45996169e86006db1b6451264ff4758223/dashboard/public/favico.svg)
on the same white background. See [OCTOP-LICENSE](OCTOP-LICENSE).
